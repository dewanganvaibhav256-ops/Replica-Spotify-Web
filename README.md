# 🎵 Spotify Web Replica

A simple and responsive **Spotify Web Player UI Replica** built using **HTML and CSS**. This project recreates the visual appearance of Spotify's web interface, including the sidebar, navigation area, music cards, and music player.

> ⚠️ This project is created for educational purposes only and is not affiliated with Spotify.

---

## 🚀 Features

- 🎧 Spotify-inspired user interface
- 🏠 Navigation sidebar
- 📚 Library section
- 🎵 Music and playlist cards
- ⏪ Previous and next navigation buttons
- ▶️ Music player controls
- 🎨 Modern dark-themed design
- 🖼️ Custom images and icons
- 📱 Responsive layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- BootStrap Icons
